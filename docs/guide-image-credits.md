# Tour Guide 圖片選用記錄

已檢視 31 張來源圖。採用 5 張作生成氣氛示意；另備 11 張具名景點實景。

## 使用規則
- 所有網頁圖片只引用 assets/guide/ 相對路徑。
- 生成圖必須顯示「AI生成イメージ／AI-generated illustration」；不可稱為附近實拍。
- 實景圖片顯示作者、來源及授權連結。景點舊照片不代表當日店舖、設施或人流狀態。
- 原 reference 圖片保持不變；編號對照見 asset-selection-review.csv。
- P3 補充圖及空庭溫泉等未選用項目仍需合適實景／来源證明，不能視為已補齊。
