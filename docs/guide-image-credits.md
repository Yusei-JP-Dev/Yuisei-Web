## 使用規則
- 所有網頁圖片只引用 assets/guide/ 相對路徑。
- 2026-10-16 起依使用者指示，網頁上不顯示任何 AI 生成標示（無圖上徽章、alt 前綴或頁尾說明）；請勿再加回或改用其他徽章。生成圖的來源只記錄於 manifest 及本文件，文字描述保持泛稱，不可稱為附近實拍或特定店舖。
- Wikimedia Commons 實景圖片顯示作者、來源及授權連結。景點舊照片不代表當日店舖、設施或人流狀態。
- 非 Commons 的實景（目前僅 life-asashiobashi-ekimae）不設 `credit` 物件，網頁只顯示店名，不列入頁尾クレジット；來源只在內部記錄，不可標成 Commons 或自由授權。
- 原 reference 圖片保持不變；編號對照見 asset-selection-review.csv。
- P3 補充圖及空庭溫泉等未選用項目仍需合適實景／来源證明，不能視為已補齊。
